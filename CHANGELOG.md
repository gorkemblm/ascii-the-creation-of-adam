# Changelog

## 1.0.0

Initial public release.

- Dependency-free `<ascii-creation>` web component with embedded artwork data.
- Medium and high ASCII densities.
- Continuous subtle movement, pointer lighting, and activation sparks.
- Responsive rendering and reduced-motion support.
- Independent instances with offscreen suspension and lifecycle cleanup.
- Single-file ES module, TypeScript declarations, and standalone HTML demo.
- Animated README preview and video.
